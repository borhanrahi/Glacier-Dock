# Glacier-Dock

Free and open-source (MIT) liquid glass smart dock for Windows 11/10 — Rust + Tauri 2.0 with a React/Vite frontend. Local-first, zero telemetry, no accounts.

## Development

```bash
npm install
npm run tauri:dev     # run the dock
npm run build         # typecheck + production frontend build
cd src-tauri && cargo check
```
